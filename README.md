
# E-Campus – College Management Website

## About the Project
E-Campus is a college major project developed as a team to create a centralized platform for college-related information and student services.

The project aims to provide an organized and user-friendly interface through which students, teachers, and visitors can explore college information and access relevant sections of the website.

## My Contribution
I worked as a team member with a primary focus on frontend design and development.

My contributions included:
- Designing and developing website pages and user interfaces.
- Creating layouts for different sections of the website.
- Working on navigation and the overall user experience.
- Improving the visual presentation and consistency of the interface.

## Key Features
- Home page and college information
- Facilities and gallery sections
- Student and teacher login interfaces
- Notices and results sections
- Contact and FAQ pages
- Student and teacher dashboard interfaces
- Admin-related sections

## Technologies Used
- HTML
- CSS
- JavaScript

## Project Purpose
This project helped me apply my frontend development knowledge in a practical team environment and understand how different website pages and components come together in a college management platform.
